# SSL Duality Control

Controls an SSL Duality console over its Remote protocol on the local network (UDP 50081): reads projects, titles, Total Recall snapshots, mix passes and channel names; opens a title, stores and recalls snapshots, names channels and sets the clock. It needs to reach the console on the studio network and receive its answers on UDP 50081 (close DualityRemote while it is used).

An add-on for AiAudioHub: get it in AiAudioHub, Explore. Namespace `jpmm-ssl-duality`, version 0.1.0.
